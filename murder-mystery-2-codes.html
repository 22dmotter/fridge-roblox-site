Murder Mystery 2 Codes (November 2026): Are There Any Working?

By Fridge · Published November 11, 2026 · Last updated: November 12, 2026

Searching for Murder Mystery 2 codes? Here's the honest answer: as of November 11, 2026, there are no working MM2 codes. Unlike some games, MM2 does have a code box, but every code ever released has expired. The last real one came out in 2019. Below you'll find the full expired list, how to redeem future codes, and the free rewards you can get instead.

How to Redeem MM2 Codes

If Nikilis ever releases a new code, this is where it goes:

  1. Launch Murder Mystery 2 on Roblox.
  2. Open your Inventory from the left side of the lobby.
  3. Find the Enter Code box in the bottom-right corner.
  4. Type the code and press Redeem.

New codes historically appeared on the developer Nikilis's X account and, occasionally, partner YouTube channels.

Free MM2 Rewards Instead of Codes

The real freebies in MM2 come from events. The Halloween 2026 event runs until November 16 at 1:00 PM ET (18:00 UTC), according to the MM2 Wiki. During it you can earn:

  • Candies from daily quests and rounds, spent in the event shop.
  • Free Halloween Keys for event crates.
  • Quest-only items and Bingo rewards that can't be bought.

After the event, playing rounds still earns coins and XP toward the battle pass and level rewards.

Watch Out for Fake "Godly Codes"

Scam warning: "MM2 Godly code" videos, "free Godly" giveaways and trading-site links are a common way to steal Roblox accounts. No MM2 code has ever given a Godly. Never type your password into a site, never paste anything into your browser console, and only trade inside the game. If your account does get stolen, follow our Roblox account recovery guide right away.

Murder Mystery 2 FAQ

Are there any working MM2 codes?

No. As of November 11, 2026, no MM2 code works. The game has a code box, but every released code has expired; the last one, COMB4T2, came out in 2019.

Has any MM2 code given a Godly?

No. Every public MM2 code gave a Common or Uncommon knife or a Common pet. 'Godly code' offers are scams.

Where do you redeem MM2 codes?

Open your Inventory in the lobby, find the Enter Code box in the bottom-right corner, type the code and press Redeem.

How can I get free items in MM2?

Play events like Halloween 2026 (until November 16) for Candies, free Keys, quest items and Bingo rewards.

Does Murder Mystery 2 still have a code box?

Yes. The redeem box is still in the Inventory, but no code works as of November 11, 2026.

How to Redeem 99 Nights Codes

  1. Launch 99 Nights in the Forest and stay in the lobby. The Codes menu doesn't open mid-run.
  2. Tap the Diamond icon in the bottom-left corner to open the Currency Shop.
  3. Press the Codes button.
  4. Type a code into the Enter Code box.
  5. Press Submit. Repeat for each code.
Tip: if awardwinner_yay says it doesn't exist, type it by hand instead of pasting. The underscore is easy to miss and pasted text can carry a hidden space. "Already redeemed" means it worked earlier on your account.

The "yay fishing" Chat Code

This one is different: you type it in chat during a run, not in the Codes menu. Trackers disagree on whether it still works (the wiki and GamesRadar+ say yes, Destructoid lists it as expired), so treat it as a bonus try.

  1. Start a solo or multiplayer run and upgrade your campfire to level 2.
  2. Find the Fishing Shack in the expanded area and grab a fishing rod.
  3. Stand at a fishing hole, equip the rod and start fishing.
  4. Open chat, type yay fishing and press Enter. If it works, 2 Diamonds drop near you. It only works once.

What to Spend Your Free Diamonds On

Diamonds buy classes in the lobby class shop. Codes give 45 Diamonds total, which is enough for a cheap starter class. Experienced players often recommend a low-cost class while you learn the game instead of saving for the most expensive one. Our 99 Nights in the Forest beginner's guide covers which early classes help most and how to survive the Deer.

Flames from codes go into the supply crate and can change events or boost your campfire, so don't ignore them.

Why a 99 Nights Code Might Fail

  • Already used: every code works once per account, so a second try shows an error.
  • Wrong place: codes are redeemed in the lobby, not during a run in the forest.
  • Expired: event codes such as happyhalloween ended after the event.
  • Extra spaces: codes aren't case-sensitive, but a trailing space can still break them.

99 Nights in the Forest FAQ

What are the working 99 Nights codes?

As of November 11, 2026: awardwinner_yay (15 Diamonds + 3 Flames), forestwakesup26 (15 Diamonds + 3 Flames) and afterparty (15 Diamonds).

Where do you redeem codes in 99 Nights in the Forest?

In the lobby, tap the Diamond icon, press Codes, enter the code and press Submit.

Are 99 Nights codes case-sensitive?

No, according to GamesRadar+. Each code can only be redeemed once per account.

Does the yay fishing code still work?

Sources disagree. The wiki and GamesRadar+ list it as working, while Destructoid lists it as expired. It only takes a moment to try while fishing.

Are 99 Nights codes case-sensitive?

No, but each code only works once per account and must be entered in the lobby.

What are Diamonds used for in 99 Nights?

Diamonds buy classes in the lobby. Cheaper starter classes are a good first purchase while you learn how to survive the nights.

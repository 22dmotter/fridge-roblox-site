The Forge Code Expiry Notes

  • The Forge codes don't show an expiry date. Most last one to three weeks, and they often end when the next update goes live.
  • SORRYFORSHUTDOWNN! and AIDASAYSSORRY are apology codes that came out after server downtime on November 7–8, 2026. Codes like these tend to be switched off quickly, so redeem them first.
  • FORGECOMEBACK and TWILIGHTWAR are on the Forge Wiki's own active list, so they're the most likely to still work later in November.
  • The weekend codes (FORGEWEEKENDS10 to 15) and event codes (HALLOWEEN26, GUILDS) have already expired.

How to Redeem Codes

  1. Open The Forge on Roblox and wait for your island to load.
  2. Open the Mailbox. The Forge Wiki says to click the mailbox (letter) icon at the top right. Roblox Den shows it through the three-line menu at the top left, then Mail.
  3. Find the Codes section and click the Enter a code box.
  4. Paste the code exactly as written, including the ! in SORRYFORSHUTDOWNN!.
  5. Press Redeem. The rerolls go straight into your race reroll count.
Requirement: None. The Mailbox, and code redemption inside it, was added in version 1.05.2 on January 21, 2026. Older videos may show a different code box.

Code Not Working? Quick Fixes

  • Check spelling and capitals. Paste the code instead of typing, and remove any space at the end.
  • Check the requirement. Level, playtime or community rules block a lot of redemptions.
  • Rejoin a new server. Some games only load new codes in servers started after the update.
  • Already used? Every code works once per account.
  • Still failing? It has probably expired. Check the disputed and expired lists above, then come back later; we update this page regularly.

The Forge Code Safety Warnings

Stay safe: real codes are only typed into the game itself. Never use a code generator, never enter your Roblox username and password on a site that promises codes or free items, and never download scripts or "auto-redeem" tools. No game code gives Robux. If a site asks you to log in, it's a scam: close it and report it.

About The Forge

The Forge is a mining, forging and fighting RPG from The Forge Community, made by FireAtacck, Umut and Cey, according to the Forge Wiki. You mine ores, forge them into weapons and armor, and fight your way through four islands, from Stonewake's Cross to the Crimson Sakura Isles. Your race gives you big passive bonuses. Codes are the main free way to get race rerolls, because rerolls otherwise cost Robux.

Tips for Using Your Free Rewards

  • Use all 45 rerolls at the Wizard's Tower or in the Race Menu. Our race reroll guide shows where.

The Level 10 Rule

Pocket Tactics says you must reach level 10 before you can redeem codes in Fish It. If you can't find the code box or it rejects everything, keep fishing until you hit level 10.

How to Redeem Fish It Codes

  1. Open Fish It! on Roblox and reach level 10.
  2. Tap the Shop icon at the top of the screen.
  3. Scroll all the way to the bottom of the Shop.
  4. Paste a code into the code box. Copy codes exactly, since an extra space breaks them.
  5. Press Redeem and check your inventory for the potions.

About Fish It!

Fish It! is a fishing simulator from Fish Atelier, first published in October 2024, with more than 4.8 billion visits. You catch fish, sell them and upgrade rods, and luck matters a lot, which is why potion codes are popular. Pocket Tactics notes that some codes expire after a set number of uses, so an old list can fail even when the code was real.

Fish It! FAQ

What Fish It promo codes work right now?

As of November 11, 2026: ELEMENTAL26 and MUTATION2 (2 Mutation II Potions each) and MERDEKA (Kerupuk Lantern).

Why can't I redeem codes in Fish It?

You need to be level 10 first. Also check the spelling, and remember each code works once per account.

Where is the code box in Fish It?

Open the Shop at the top of the screen and scroll to the bottom.

Do DIVING and YEEHAW still work in Fish It?

They're disputed. Only one independent tracker lists them as active, so they may have expired.

Who makes Fish It?

Fish Atelier, according to the official Roblox game page.

Do Fish It promo codes have limited uses?

Some do. Pocket Tactics says certain Fish It promo codes expire after a set number of uses, so an old list can fail even if the code was real.

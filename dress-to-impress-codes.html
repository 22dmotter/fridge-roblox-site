DTI Code Expiry Notes

  • Creator and collab codes (like LANA, LEAHASHE and LABOOTS from February 2024) have no announced end date and are still active.
  • Event codes expire fast: 10BILLION expired October 17 and RDC2026 ran only September 11–19, 2026.
  • When an item is reworked, its old code is retired and replaced (LANATUTU became LANADOLLDRESS).
  • The Tales of the Dark King quest ends November 14, 04:00 UTC (November 13, 11 PM ET). It has no code.

How to Redeem DTI Codes

  1. Open Dress To Impress on Roblox and join a server.
  2. During intermission or the dressing phase, click the handbag (Codes) button on the left of the screen.
  3. Type or paste one code into the Enter code here! box.
  4. Press Redeem; the item is added straight to your wardrobe.
Requirement: DTI codes are case-sensitive and use numbers in place of letters (CH00P1E has zeros, 3NCHANTEDD1ZZY has a 3 and a 1). Copy and paste instead of typing. Note that LANADOLLDRESS uses the letter O.

These no longer work, according to Roblox Den's expired list and the other trackers we checked: 10BILLION, RDC2026, PROUD, KATSEYE, LNY, LIONDANCER, BHM26, 2026BADDIES, 2YEARS, 2GETHER, GLINDA, ELPHABA, FACECARD, BADDIE4LIFE. If a code says invalid or expired, it's gone for good.

Code Not Working? Quick Fixes

  • Check spelling and capitals. Paste the code instead of typing, and remove any space at the end.
  • Check the requirement. Level, playtime or community rules block a lot of redemptions.
  • Rejoin a new server. Some games only load new codes in servers started after the update.
  • Already used? Every code works once per account.
  • Still failing? It has probably expired. Check the disputed and expired lists above, then come back later; we update this page regularly.

DTI Code Safety Warnings

Stay safe: real DTI codes are only typed into the game itself. Never use a code generator, never enter your Roblox username and password on a site that promises codes or free items, and never download scripts or "auto-redeem" tools. No game code gives Robux. If a site asks you to log in, it's a scam: close it and report it.

About Dress To Impress

Dress To Impress is the Roblox fashion game where you dress for a theme, walk the runway and get voted into the top three. It's made by the Dress To Impress Group, launched in October 2023 and has more than 11.3 billion visits. Codes give free clothing, hair and accessories from creator collabs, so they're the easiest way to grow your wardrobe without Robux. Unlike most games, Dress To Impress codes rarely expire unless they're tied to an event, which is why this list is so long.

Tips for Using Your Free Rewards

  • Redeem every creator code once; items from Dress To Impress codes stay in your wardrobe forever.
  • Mix code items with themed outfits. Bunny Slippers, Mermaid Tail and Biker Helmet fit a lot of themes.
  • Play Halloween minigames and daily tasks for Candy Corn while the event lasts.
  • Need outfit ideas? Our Roblox avatar ideas guide works great for runway themes too.

Where to Find New DTI Codes

New DTI codes usually appear first in posts from @_Dress2Impress on X, in the in-game update notes and in the official Discord (linked on the game's Roblox page). The game released codes in past Novembers (4BILLION in 2024, GLINDA and ELPHABA in 2025) and a New Year code each December, but nothing is announced yet.

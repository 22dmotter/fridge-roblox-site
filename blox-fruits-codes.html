How to Redeem Blox Fruits Codes

  1. Launch Blox Fruits on Roblox and choose Pirates or Marines.
  2. Click the gear (Settings) icon on the left side of the screen.
  3. Choose Redeem DLC Code (older guides call it the Redeem button).
  4. Type or paste one code into the box exactly as written.
  5. Press Redeem. Rewards apply instantly. Repeat for the next code.
Code not working? Check for a stray space at the end, match the capital letters and underscores, then try once more. If it still fails, it has probably expired. Never enter your Roblox password on a site that promises "secret" Blox Fruits codes or free fruits.

Best Order to Use Blox Fruits Promo Codes

2x EXP timers start the moment you redeem, so a little planning goes a long way:

  1. Use a stat reset first if you want to move points, for example when you switch from sword to fruit builds. You get three resets from codes: SUB2GAMERROBOT_RESET1, KITT_RESET and Sub2UncleKizaru.
  2. Get to a good grinding quest before you touch the EXP codes.
  3. Stack the EXP codes. Trackers report that 2x EXP time stacks, so all 17 EXP codes together add roughly 4.5 to 5.8 hours of double EXP.
  4. Grab the small ones any time. BIGNEWS, fudd10, fudd10_V2 and Chandler give tiny rewards.

Blox Fruits FAQ

What are the newest Blox Fruits promo codes?

The newest working code is EASTEREXP, added in March 2026, which gives 20 minutes of 2x EXP. No new code has been confirmed since, including for Halloween 2026.

Are there Blox Fruits promo codes for free fruits?

No. Working Blox Fruits promo codes only give 2x EXP, stat resets, small amounts of Beli and a title. Sites promising fruit codes are fake.

How do I redeem Blox Fruits promo codes?

Open Settings with the gear icon on the left, choose Redeem DLC Code, type the code exactly and press Redeem.

Do Blox Fruits 2x EXP codes stack?

Code trackers report that 2x EXP time stacks, so redeeming several EXP codes back to back extends your boost.
